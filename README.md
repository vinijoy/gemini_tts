# Gemini 3.8 TTS 사용 안내

대본을 입력하고 목소리를 골라 음성을 만드는 웹 앱입니다. 한 목소리의 내레이션이나
두 화자가 주고받는 대화를 만들고, 완성된 음성을 파일로 저장할 수 있습니다.

## 시작하기

실행 중인 앱의 주소를 브라우저에서 여세요. 로컬에서 실행한 경우 기본 주소는
[localhost:3000](http://localhost:3000)입니다. 직접 설치·실행하려면
[개발·운영 안내](docs/DEVELOPMENT.md#개발-환경과-운영)를 참고하세요.

화면에는 **음성 만들기**, **목소리 제작·관리** 두 탭이 있습니다.
처음에는 **음성 만들기**에서 기본 설정으로 시작하세요.
음성 생성과 목소리 제작은 연결된 API 계정에 요금이 발생할 수 있습니다.

## 첫 음성 만들기

1. **모델과 화자**에서 기본 모델과 **한 화자** 모드를 유지합니다.
2. **목소리 선택**에서 **기본 목소리**를 고르고 사용할 목소리를 선택합니다.
3. **대본과 연출**에 읽을 대본을 입력합니다.
4. 필요하면 **연출 지시**에 `차분하고 따뜻하게 읽어 주세요.`처럼 말투를 적습니다.
   읽을 내용과 연출 지시는 각각 별도 입력칸에 작성합니다.
5. **출력 설정**은 처음에는 원본 음성·24,000헤르츠·표준을 유지합니다.
6. **음성 생성 시작**을 누릅니다. 생성되는 동안 음성이 재생되며, 중간에 취소할 수 있습니다.
7. 생성이 끝나면 **다시 듣기**로 확인하고 **음성 파일 다운로드**로 WAV 파일을 저장합니다.
   출력 설정에 맞는 파일은 **선택 형식 다운로드**를 사용합니다.

대본과 연출은 입력칸마다 각각 1,000자까지 입력할 수 있습니다.
웃음·한숨·기침·숨소리·휴지 버튼은 대본 끝에 효과 태그를 추가합니다.
필요한 위치로 옮겨 사용하고, 태그를 연속으로 넣는 것은 피하세요.
말투나 분위기를 계속 유지하고 싶을 때는 연출 지시에 적으세요.

취소하거나 오류로 중단된 음성은 완성본으로 다운로드할 수 없습니다.
마지막 대사까지 정상적으로 생성되어야 다시 듣기와 다운로드가 활성화됩니다.

## 두 화자의 대화 만들기

1. **화자 모드**에서 **두 화자 대화**를 선택합니다.
   직접 만든 목소리가 포함되면 **맞춤 목소리 대화**를 선택합니다.
2. 첫 번째 화자 A와 두 번째 화자 B의 목소리를 각각 선택합니다.
3. 대본에 다음처럼 화자 이름과 콜론을 붙여 입력합니다.

```text
A: 안녕하세요. 오늘 이야기를 시작해 볼까요?
B: 좋아요. 먼저 어떤 내용을 소개할까요?
```

A와 B 대신 인물 이름을 쓸 수도 있습니다. 전체 대본에서 처음 나온 이름이 첫 번째 목소리,
다음 이름이 두 번째 목소리로 연결되며 다음 대사 칸에서도 같은 연결을 유지합니다.
지원하는 화자는 최대 두 명입니다.

대화가 길면 **대사 추가**로 입력칸을 늘립니다. 추가한 대사마다 화자·대본·연출을 지정하고,
필요하면 위로 이동하거나 삭제할 수 있습니다. 화자 이름 없이 쓴 대사는 해당 칸에서
선택한 화자가 읽습니다. 각 칸의 연출은 그 칸에 있는 모든 발화에 적용됩니다.

대본을 모두 작성한 뒤 **음성 생성 시작**을 누릅니다.

## 확장·저장 목소리 고르기

**목소리 선택 방법**에서 **확장·저장 목소리**를 선택합니다.
화자 A와 B는 각각 목소리를 고를 수 있습니다.

1. **목록 출처**를 선택합니다. **사용자 제공 목록**은 보관된 목록이고,
   **현재 계정**은 연결된 계정에서 조회합니다.
2. **목소리 종류**에서 제공되는 목소리 또는 제작해 저장한 목소리를 선택합니다.
3. **목록 새로고침**으로 목록을 불러옵니다.
4. 표시되는 분류 선택란으로 후보를 좁힌 뒤 **목소리**에서 원하는 항목을 선택합니다.

보관 목록에 있다는 사실만으로 현재 계정에서 사용할 수 있다는 뜻은 아닙니다.
미리듣기가 제공되지 않는 목소리도 있습니다.

## 목소리 제작과 관리

**목소리 제작·관리** 탭에서 제작 방식을 고르고 이름과 필요한 정보를 입력합니다.
**목소리 생성 (유료 요청)**을 누르면 실제 제작 요청을 보냅니다.
기능의 사용 가능 여부는 연결된 계정과 API 지원에 따라 달라질 수 있습니다.

### 설명으로 만들기

설계 설명에 원하는 목소리의 특징을 1~2문장으로 적습니다. 예를 들어
`차분하고 또렷한 한국어 안내 목소리`처럼 작성합니다. 설명은 최대 2,000자입니다.
목소리를 생성한 뒤 **이 목소리를 화자 A에 선택**을 눌러 사용할 수 있습니다.
미리듣기가 제공되면 결과를 들어 보세요.

### 본인의 녹음으로 복제하기

성인 본인의 목소리만 사용하며 다음 두 파일을 따로 준비합니다.

- **참조 녹음**: 10~30초 분량의 본인 목소리
- **공식 동의문 녹음**: 화면에 표시된 공식 영어 동의문을 같은 사람이 그대로 읽은 녹음

두 파일 모두 **모노 PCM16 WAV** 형식이어야 합니다. 24kHz를 권장하며,
파일당 최대 5MiB, 동의 녹음은 최대 60초까지 지원합니다.
파일 확장자만 WAV로 바꾸는 것으로는 변환되지 않습니다.

두 파일을 첨부하고 본인 동의·동일 화자·동의문 확인란을 모두 확인한 뒤 생성합니다.
나중에 다시 사용하려면 **프로젝트에 저장**을 선택하세요.
저장하지 않은 복제 목소리는 현재 화면에서만 유지되며, 새로고침하면 사라집니다.
비저장 복제 키의 유효 기간은 7일입니다.

### 저장 목소리 조회·삭제

저장 목소리는 프로젝트에서 공유하며 최대 200개까지 보관할 수 있습니다.
마지막 사용 후 1년이 지나면 만료됩니다.

**목소리 ID**를 입력하고 **목소리 상세 조회**를 누르면 해당 목소리를 확인할 수 있습니다.
삭제하려면 조회된 ID를 확인한 뒤 삭제 확인란에 체크하고 **확인한 목소리 삭제**를 누르세요.
공유 목소리를 삭제하기 전에 다른 사용자가 사용하는지 확인하세요.

## 문제가 생겼을 때

- **앱이 열리지 않습니다.** 서버가 실행 중인지 확인하세요. 직접 실행하는 경우
  [개발·운영 안내](docs/DEVELOPMENT.md)를 확인하세요.
- **생성이 실패합니다.** 화면의 오류 안내를 먼저 확인하세요. 대본을 짧게 나눠 보고,
  계정·키·권한 오류는 서버를 설정한 사람에게 문의하세요.
- **생성 대기가 깁니다.** 여유 처리 등급은 대기가 길 수 있습니다. 필요하면 취소하세요.
  앱은 다른 비용 등급으로 자동 전환하지 않습니다.
- **다운로드 버튼이 활성화되지 않습니다.** 마지막 대사까지 생성이 끝나야 합니다.
  취소·연결 단절·오류로 중단되었다면 다시 생성해야 합니다.
- **목소리 목록이 비거나 제작에 실패합니다.** 목록 출처와 종류를 확인하고 새로고침하세요.
  보관 목록과 현재 계정의 접근 권한은 다를 수 있습니다.
- **복제 파일을 사용할 수 없습니다.** 녹음 형식·길이·용량과 동의 확인 항목을 확인하세요.
