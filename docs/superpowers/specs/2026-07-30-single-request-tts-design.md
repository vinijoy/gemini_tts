# 단일 요청 TTS와 1,000자 입력 제한 설계

## 목표

장문을 여러 Gemini 요청으로 나눌 때 조각마다 언어와 연기 해석이 달라지는 문제를 제거한다.

## 확정 동작

- 본문 전체를 Gemini TTS에 한 번의 생성 단위로 전달한다.
- 자동 문장 분할, 순차 결합, 반복 실패 조각의 재귀 세분화를 제거한다.
- 본문 입력란은 HTML `maxLength=1000`과 상태 갱신 시 `slice(0, 1000)`을 함께 적용해 키보드 입력과 붙여넣기를 모두 1,000자에서 차단한다.
- 감정 태그 버튼으로 추가되는 문자열도 남은 글자 수 안에서만 반영한다.
- API는 1,000자를 초과한 본문을 HTTP 400과 한국어 오류로 거부한다.
- 기존 PCM 스트리밍, 정상 종료 검사, 동일 요청 재시도, 다시 듣기와 다운로드 동작은 유지한다.

## 검증

- UI에서 1,000자를 초과해 입력하거나 붙여넣어도 값이 1,000자를 넘지 않는다.
- API는 1,001자를 거부한다.
- 1,000자 이내 본문은 Gemini 호출 한 번으로 전달된다.
- 전체 테스트, 린트, 프로덕션 빌드를 통과한다.
