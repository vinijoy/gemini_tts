# Gemini TTS Web UI

## What This Is

Gemini 음성 합성으로 대본을 재생하고 WAV로 저장하는 접근성 중심 웹 앱이다. 콘텐츠 제작자가 한국어 화면에서 목소리와 연출을 선택하고, 한 대본의 두 화자와 설명 기반 맞춤 목소리를 사용할 수 있도록 기존 앱을 확장한다.

## Core Value

대본과 연출 의도를 보존하면서 공식 지원 음성 기능을 쉽게 사용하고, 검증된 완성 음성을 재생·저장한다.

## Requirements

### Validated

- ✓ 단일 요청 TTS, 첫 PCM부터 스트리밍 재생, 완료 후 재생·WAV 다운로드 — 기존 코드로 확인; 실제 청취 수용과는 구분한다.
- ✓ 1,000자 입력 검증, 취소, 첫 PCM 이전 제한적 429 재시도 — 기존 구현과 테스트.
- ✓ 한국어 안내, 레이블·상태 알림, Web Audio 재생 — 기존 구현; 스크린리더 실기 보증은 아님.

### Active

- [ ] Gemini 3.8 Flash TTS와 Gemini 3.8 Flash-Lite TTS의 공식 모델 ID를 선택·호출한다.
- [ ] 공식 문서를 수집하고 지원 기능·제약을 전수 대조하여 기능별 구현과 검증 근거를 기록한다.
- [ ] 문장형 연출을 대본과 분리하고, 인라인 발성·휴지 태그와 두 화자 대화를 지원한다.
- [ ] 기본·확장 목소리와 설명 기반 Voice Design을 지원하고, 공식 Voice Replication 및 관련 기능을 확인하여 반영한다.
- [ ] GEMINI-TTS-VOICES.md를 언어·지역 → 성별 표현 → 이름 순으로 작성한다. API 접근 실패나 공식 메타데이터 부재를 추정으로 채우지 않는다.
- [ ] 기존 재생·취소·오류 복구를 보존하고 자동 검사와 남은 실기 확인을 구분한다.

### Out of Scope

- 배포, push, main 병합 — 별도 사용자 요청 없음.
- 생성 이력·BGM 믹싱·계정 시스템 — 이번 모델 기능 업데이트와 무관한 기존 PRD의 미래 아이디어.

## Context

- 2026-10-11 사용자가 gsd-quick 업데이트를 요청했고, ROADMAP 부재로 초기화가 필요하다는 설명 뒤 초기화하고 진행하라고 승인했다.
- Next.js 16.2.12, React 19.2.4, TypeScript, 기존 @google/genai 1.50.1 계열. 정본은 package-lock.json과 실제 설치 패키지다.
- 기존 구조는 .planning/codebase/를 참조한다. 기존 .serena/ 및 docs/graphify-out 관련 미추적 파일은 사용자 상태로 보존한다.
- 공식 원문은 docs/google-gemini/에 전체 HTML을 Markdown 코드 블록으로 보관하고 document_sources.py로 등록한다.
- 요청의 “Flash Lite”는 문맥상 공식 TTS 모델 gemini-3.8-flash-lite-tts를 뜻한다.

## Constraints

- **사실성**: 공식 원문과 모델별 지원 여부를 대조하고 추정 기능·목소리 속성을 만들지 않는다.
- **접근성**: 모든 새 입력에 레이블과 키보드 접근을 제공하고 상태·오류를 한국어로 알린다.
- **보안**: API 키는 서버에서만 사용하며 비밀값을 로그·문서·클라이언트에 노출하지 않는다.
- **비용**: 자동 검사는 mock 기반으로 진행한다. 유료 생성·목소리 생성 호출을 검증 목적으로 자동 실행하지 않는다.
- **보존**: 기존 취소·재시도·PCM 경계와 입력 상한을 유지한다. 공식 한도와 앱 자체 제한을 구분한다.
- **실행**: 초기화 후 요청한 quick 워크플로로 구현한다. quick 완료와 로드맵 단계의 실기 수용을 혼동하지 않는다.

## Key Decisions

| Decision | Rationale | Outcome |
|----------|-----------|---------|
| 기존 앱을 GSD로 초기화하고 quick으로 업데이트 | 사용자 명시 승인 | 진행 중 |
| 권장 자동 진행·병렬 작업·계획 문서 Git 추적, 현재 모델 상속 | 사용자 전역 실행 선호와 Codex 호환성 | 적용 |
| 공식 3.8 스키마에 맞춰 연출·대본 분리 | 3.8은 text를 그대로 낭독 | 공식 문서 확인 |
| 현재 기능 보존 중심 MVP 단계 | 동작 가능한 단위로 검증 | 계획 중 |

## Evolution

단계 전환마다 실제 검증된 요구사항, 새 요구사항, 범위 변경과 의사결정을 갱신한다. 마일스톤 종료 시 핵심 가치·문맥·제외 범위를 검토한다. 자동 검사만으로 실제 청취나 VoiceOver 수용을 완료 처리하지 않는다.
