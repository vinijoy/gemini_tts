# 음성 생성 탭의 작업 순서 정리

1. 모델·화자 모드 → 목소리 → 대본·연출·태그·추가 발화 → 출력 설정 → 생성·결과 순으로 DOM과 화면 순서를 일치시킨다. 섹션 제목으로 빠른 탐색을 제공한다.
2. TtsEditor를 설정/두 번째 목소리/추가 발화/출력 부분으로 배치할 수 있게 하되 요청 상태·기본 렌더링 계약을 유지한다. 기본 목소리 둘은 같은 영역에서 선택하고 확장 목소리 방식에서는 중복 기본 선택을 노출하지 않는다.
3. 단일·대화·확장 모드의 탐색 순서, 입력 보존, 기존 회귀 검사와 lint/타입 검사를 수행한다. API 호출·청취·VoiceOver 실기는 자동 성공으로 처리하지 않는다.

<threat_model>ASVS 1, high 차단: UI 배치만 수정하며 서버/키/외부 호출을 추가하지 않는다. hidden/inert/TabSelect 및 입력 검증을 유지한다.</threat_model>

## 실행 방식 및 보존
GSD Codex single-agent gate의 순차 실행과 스킬의 inline 대체 경로를 사용한다. 별도 서브에이전트 요청 없음. 기존 미커밋 파일은 before 사본으로 보존하고 이번 작업에서 기존 변경을 일괄 커밋하지 않는다. 선행 변경 의존으로 독립 커밋이 불가능하면 정식 quick 완료 대신 구현·검증 결과와 커밋 대기를 기록한다. ROADMAP/요구사항/UAT 판정은 변경하지 않는다.
