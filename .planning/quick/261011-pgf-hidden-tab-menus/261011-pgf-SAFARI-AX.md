# Safari native AX 관찰 (2026-10-11)

도구: `mcp__cua_repl`, `cua.getApp('com.apple.Safari')`, `getAXState({emit:false, disableDiffing:true})`. 이미 열린 `Gemini 3.8 TTS` / `localhost:3000/`에서 탭을 클릭했다. 아래 목록은 실제 전체 AX 출력 중 HTML 콘텐츠 범위에서 관찰한 팝업 버튼 이름만 옮겼다. 브라우저 도구막대·북마크 정보는 제외한다.

| 활성 탭 | HTML 콘텐츠 내 팝업 버튼 수 | 실제 이름 |
| --- | --- | --- |
| 음성 만들기 (기존 두 화자 모드) | 9 | 음성 선택, 화자 A 공식 기본 목소리, 화자 B 공식 기본 목소리, 모델, 화자 모드, 화자 B 기본 목소리, 출력 형식, 샘플레이트, 요청 처리 등급 |
| 목소리 제작·관리 | 4 | 제작 방식, 제작 모델, 목소리 언어, 목소리 성별 표현 |
| 일괄 작업 | 1 | 입력 제출 방식 |

각 전체 트리에서 `탭 그룹 음성 작업` 다음에는 활성 탭과 같은 이름의 container가 이어졌고 위 팝업은 모두 그 안에 있었다. 그 사이에 불필요한 익명 메뉴는 관찰되지 않았다. 생성 → 제작 → 일괄 → 생성 왕복을 확인했고 마지막 선택 및 초점은 `음성 만들기` 탭이었다. 입력값 변경, 서비스 호출, 업로드, 유료 생성 버튼 클릭은 하지 않았다.

수정 전 Safari AX 기준은 확보하지 않았다. 수정 전 4+1은 DOM 증거다. VoiceOver를 실행하거나 발화를 들은 기록이 아니므로 실제 VoiceOver/NVDA 수용은 미확인으로 유지한다.

## 사용자 VoiceOver 확인 — 2026-10-11

빈이가 수정 후 “보이스오버에서도 문제 없다.”고 직접 확인했다. 이번 탭 그룹과 탭 패널 사이의 불필요한 메뉴 문제는 사용자 VoiceOver 수용 통과로 기록한다. 앞선 미확인 표시는 당시 에이전트 검사 범위이며 이 사용자 확인이 해당 문제의 최신 상태다. 에이전트가 직접 발화를 청취한 것으로 기록하지 않는다. NVDA·앱 전체 접근성·실제 생성 음성 품질 또는 커밋 마감까지 완료된 뜻은 아니다.
